# Git_Seminario

Problema:
La problemática principal es la falta de un ecosistema educativo estructurado y alineado con la formación universitaria. La ausencia de este ecosistema limita el desarrollo del aprendizaje autodidacta y multidisciplinario en los estudiantes.

Objetivo:
Desarrollar una plataforma web centralizada que fomente el aprendizaje autodidacta y multidisciplinario mediante un ecosistema educativo estructurado con videos temáticos y actividades dinámicas.
